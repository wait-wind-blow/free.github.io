1. 下载与安装

Windows 用户推荐下载安装版。请只从澄答 AI 官方下载页获取文件。下面从“进入下载页”开始，一步一张图。

1

进入官方下载页

找到“Windows 下载”区域，点击最新版本的安装包。便携版无需安装，普通用户优先选择安装包。

2

打开下载菜单

Edge 若提示“通常不会下载”，把鼠标移到该下载项，点击右侧的三个点。

3

选择“保留”

在展开的菜单里点击“保留”。这一步不会关闭系统安全功能。

4

确认“仍然保留”

在确认窗口中展开右下角按钮，选择“仍然保留”。

5

安装并打开软件

下载完成后打开安装包，按向导安装。看到澄答 AI 欢迎页，说明程序已正常启动。

安全提示只保留从官方发布页下载、文件名和版本正确的安装包。不要关闭 Windows Defender，也不要对来源不明的 EXE 执行上述操作。

2. 首次打开

第一次运行会出现四页快速向导。可以先了解功能，再进入工作台完成配置。

1

欢迎页

确认当前版本和主要功能，点击右下角“下一步”。

2

了解 API 配置

软件需要用户自己的模型 API。这里先阅读说明，稍后会在 API 设置页正式填写。

3

了解资料库

资料库用于存放简历、项目和岗位信息。相关问题会优先按照资料内容回答。

4

进入工作台

阅读练习方式后点击“开始使用”，进入软件主页。

完成后会进入工作台。建议先配置 API，再导入资料，最后开始笔试或面试。

3. API 与模型配置

阿里百炼和硅基流动任选一个配置即可。新用户推荐阿里百炼；已有硅基流动 Key 的用户仍可继续使用。两个服务商的 Key 会分别保存，切换服务商不会覆盖另一份配置。

服务商配置中心阿里百炼图文注册硅基流动图文配置
1

打开 API 设置

进入工作台后，点击左侧“API 设置”。

2

选择服务商并填写 Key

先选择阿里百炼或硅基流动，再粘贴对应平台的 API Key。Key 与服务商必须匹配。

3

选择文字、截图和语音模型

直接使用推荐项即可，也可以输入平台控制台中可用的完整模型 ID。需要语音热词时选择支持热词的语音模型。

4

保存并测试连接

点击“保存设置”，再点击“测试连接”。看到成功提示后再开始练习。

测试成功即表示当前服务商可用。模型注册、免费额度和计费说明请查看上方独立专题页。

4. 导入资料库

资料库可导入 TXT、Markdown、CSV、JSON、LOG 和 DOCX。问题与简历相关时优先按原文回答；不相关时由 AI 正常作答，不会生搬硬套简历。

1

打开“资料库”

点击左侧“资料库”，进入资料管理页。

2

选择并导入文件

点击“导入资料”，选择简历或岗位资料。建议姓名、学历、项目、实习和目标岗位写具体。

3

检查抽取结果

导入后检查资料名称和文字内容。扫描图片式 DOCX 如果没有可选中文字，请先用 Word 或 OCR 转成文本。

回答规则命中资料时优先保留姓名、学校、项目、数字和经历顺序；资料未覆盖的问题由模型自由回答。

5. 外观与全局快捷键

1

调整字体大小

点击左侧“外观”，拖动字体缩放滑块。最大可调到 200%，设置会立即应用。

2

录入快捷键

打开“设置”，点击要修改的快捷键输入框，然后按下新的组合键并保存。

操作默认键
笔试查题Ctrl+Alt+S
隐藏练习窗Ctrl+Alt+H
开始/暂停面试监听Ctrl+Alt+P
重置当前内容Ctrl+Alt+C
恢复隐藏窗口Ctrl+Alt+R

6. 笔试查题

先从工作台打开笔试练习，再把题目清晰地显示在主屏幕上。

1

打开笔试练习

在“练习入口”区域点击“开始笔试练习”。

2

显示题目并开始查题

让题目文字和选项完整清晰地出现在主屏幕。悬停“查题”1.2 秒，或按 Ctrl+Alt+S。

3

查看、复制或重置答案

识别和回答耗时会实时显示。点击“复制”复制答案；下一道题前点击“重置”。长回答卡住时可直接取消。

提高识别率题目不要被其他窗口遮挡，系统缩放不宜过高，文字与背景需有明显对比。软件会按当前屏幕原始分辨率截图，不建议二次压缩题图。

7. 面试问答

面试模式采集 Windows 正在播放的系统声音，识别面试官的问题后，以候选人第一人称逐字输出答案。

1

打开面试练习

在工作台“练习入口”中点击“开始面试练习”。进入会话时会预热当前文字模型。

2

开始监听系统声音

点击“开始监听”。播放面试官声音后，识别文本和回答会依次出现。

3

暂停、继续或取消

需要停一下时点击“暂停”，之后可继续，已有记录不会丢失。识别或回答卡住时点击“取消”。

4

查看历史问答

在问答区域滚动鼠标滚轮可查看前面的内容。向上查看时，页面不会强制跳回底部。

识别准确率默认 qwen3-asr-flash-realtime 速度优先。需要热词增强时，在 API 设置中选择 qwen-audio-3.0-asr-flash-streaming，并填写热词表；同时避免回声和多人重叠。

8. 手机笔试 / 手机面试

手机与电脑需连接同一个、允许设备互访的私人 Wi-Fi。不要在公共网络分享临时地址。

1

展开手机共享

在工作台找到“手机笔试 / 手机面试”，点击展开。

2

开启共享并在手机打开地址

点击开启手机共享；电脑显示临时地址后，用手机浏览器打开它。

3

选择笔试或面试

手机成功连接后，在电脑点击对应的开始按钮。主界面会正常隐藏到托盘，单击托盘图标即可恢复。

9. 购买激活码与软件更新

1

打开购买激活码

点击左侧“购买激活码”，查看激活说明并进入购买页面。激活码只包含软件使用时长，不包含第三方 API 费用。

2

输入激活码

购买后打开“API 设置”，在顶部“软件激活”区域输入激活码并点击“激活完整版”。限时码会叠加到当前剩余时间。

3

检查软件更新

点击左侧“检查更新”，再点击右上角“检查更新”。发现新版本后会显示本次更新内容。

4

下载并等待自动替换

确认更新后观察真实下载进度条；随后依次完成校验、准备替换和重启。若自动更新失败，可从页面打开 GitHub 发布页手动下载。

在线手册无需更新软件网页内容可独立更新，不需要重新安装桌面端。

10. 常见问题

提示或现象处理方法
error sending request for url检查网络、DNS、系统代理/VPN、防火墙和 Base URL；新版会对临时网络故障有限重试。
400 / enable_thinking确认运行 v0.5.12 或更高版本。新版不会向不支持该参数的硅基流动模型发送 enable_thinking。
401 / 403重新复制 API Key，并检查对应平台的账号权限、余额与服务商风控。
404 / model not found完整复制模型 ID，并确认模型属于当前选择的服务商且账号可用。
500 / 50507通常是模型服务临时过载。稍后重试，或在 API 设置中切换另一个可用模型。
无法识别题目确保题目完整、清晰、未被遮挡并显示在主屏幕；避免截图过小或二次压缩。
语音断续或英文不准减少回声与多人重叠；专业名词可启用支持热词的语音模型，并添加中英文热词。
隐私说明API Key 保存到系统凭据管理器；资料和练习记录保存在当前设备。调用模型时，截图、音频转写或问题文本会发送给用户自己配置的 API 服务商。
