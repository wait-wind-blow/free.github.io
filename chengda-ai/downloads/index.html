macOS v0.4.6 更新内容

  • 新增 macOS 通用版，Apple 芯片与 Intel Mac 均可使用同一个 DMG 安装包
  • 新增应用自有窗口兼容隐私保护，减少支持的截图和录屏路径意外包含练习悬浮窗
  • Mac 截图查题会在捕获瞬间自动避开本应用窗口，题目画面更干净
  • 截图查题悬停缩短为 1.2 秒，隐藏、重置、监听和退出仍保留 1.5 秒防误触
  • 首次打开新增四步使用引导，也可从左侧随时重新查看
  • API 服务与常用模型仍可自由选择，密钥保存在 macOS 钥匙串中
  • 资料库支持 DOCX 等常用格式和简历样例，回答时会优先复用个人资料
  • 限时激活可继续叠加，本机剩余时间显示和到期提醒更加清晰

Windows v0.4.7 更新内容

  • 视觉模型列表已按硅基流动当前可用目录更新，移除已弃用的 72B 等旧模型选项
  • 新增 Kimi K2.6、Kimi K2.7-Code、Qwen3.5、Qwen3-VL、Qwen3-Omni 等常用视觉模型
  • 启动时检测到新版本会显示与用户有关的更新内容，可选择暂不更新或下载更新
  • 旧配置若保存了已弃用的视觉模型，会自动切换到当前可用的默认模型
