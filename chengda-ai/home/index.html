软件是否自带 AI API 额度？

不自带。用户需要自行购买并配置阿里百炼或其他兼容服务的 API，激活费用不包含第三方模型费用。

Windows 安装包和单 EXE 有什么区别？

安装包适合普通用户；单 EXE 无需安装，适合便携使用。两者提供相同的核心桌面功能。

防捕获功能是否保证任何录屏都看不到？

不能保证。软件使用操作系统公开能力保护本应用窗口，但摄像机、特殊驱动和部分第三方路径可能不受支持。

激活码到期后还能打开软件吗？

主页、设置、资料库与更新等基础页面仍可查看；进入笔试或面试练习时会提示激活。
