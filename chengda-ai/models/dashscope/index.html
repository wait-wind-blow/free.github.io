阿里百炼配置指南

从账号开通、API Key 到模型和语音热词，按顺序完成即可。澄答 AI 已为百炼准备好默认快速模型，也支持直接填写控制台中可用的完整模型 ID。

开始配置返回服务商选择操作手册

1. 注册账号并创建 API Key

澄答 AI 默认使用中国内地（北京）百炼线路。账号、地域、API Key 和模型开通范围必须一致。

  1. 注册或登录阿里云，按账号页面要求完成实名认证。
  2. 打开阿里百炼控制台，阅读协议并开通百炼。首次开通后免费额度可能需要一段时间显示。
  3. 进入API Key 管理创建通用百炼 Key，复制完整的 sk-... 密钥。
  4. 在模型广场确认需要的文本、视觉和语音模型可用；语音模型需在工作空间内单独开通。
  5. 在澄答 AI“API 设置”选择“阿里百炼（推荐）”，保持默认 Base URL，填写 Key、选择或手输模型 ID，保存后测试连接。

默认 Base URL

https://dashscope.aliyuncs.com/compatible-mode/v1

密钥安全

不要把 Key 发给他人或上传到公开仓库。怀疑泄露时立即在控制台删除并重新创建。

2. 模型自选与语音热词

软件的文本、截图、语音三个模型栏都可从推荐项选择，也可直接输入百炼控制台显示的完整模型 ID。

用途默认 / 推荐说明
文本快速qwen3.5-flash默认快速档，Thinking 关闭，适合面试短答和日常问题。
文本质量qwen3.5-plus复杂问题更稳，通常比 Flash 慢。
截图识题qwen3.6-plus单个多模态请求同时识别截图并直接作答。
语音快速qwen3-asr-flash-realtime默认实时识别；该模型不使用热词。
语音热词增强qwen-audio-3.0-asr-flash-streaming支持即时热词、预编译热词表与上下文增强。
手动热词表怎么用在“API 设置 → 语音热词表”中每行或用逗号填写一个人名、公司名、技术名词或英文词组。软件会去重并以权重 4 在每次语音任务开始时预加载；开始填写时会自动切换到支持热词的语音模型。
预编译热词表 ID词表长期固定时，可先按百炼热词文档创建预编译词表，再把 vocabulary_id 填入软件。即时热词与预编译词表可同时使用，合并后最多 2,000 个。
热词格式限制含中文等非 ASCII 字符的单个热词最多 15 个字符；纯英文热词按空格分段后最多 7 个词。热词应是实际术语，不要粘贴整段提示词。

3. 新用户额度、按量付费与 Token Plan

价格和活动可能调整。页面核对日期：2026-09-04；付款前请再次查看阿里云控制台。

新用户免费额度

首次开通百炼后自动发放，不需要单独领取。当前规则为有效期 90 天；额度按模型独立计算，通常每个模型 100 万 Tokens，但并非所有模型都参加。免费额度只覆盖实时推理。

按量付费 澄答 AI 推荐

使用通用 sk- Key，先扣免费额度，再按各模型输入 / 输出 Token 或语音时长计费。实名认证并充值的账号在免费额度耗尽后通常会继续扣费，可在控制台开启“仅免费额度”防止意外费用。

Token Plan

Lite / Standard / Pro 当前限时价分别为 39 / 139 / 499 元每月，每 7 天限额 2,500 / 10,000 / 40,000 Credits。它是个人编程与智能体工具订阅，不等同于通用 API 余额。

Token Plan 不要填入澄答 AI阿里云当前规则只允许在指定编程或智能体工具中交互使用，不允许用于自定义应用程序后端、自动化脚本或非交互批量调用。澄答 AI 应使用通用按量付费 sk-... Key，不要使用 Token Plan 专用 Key。
