SILICONFLOW SETUP

硅基流动配置指南

澄答 AI 继续支持原有硅基流动线路。已经配置好的 API Key 和模型可以继续使用，也可按硅基流动模型广场中的完整 ID 自行更换。

开始配置返回服务商选择操作手册

1. 注册账号并创建 API Key

  1. 在硅基流动控制台注册或登录，按控制台要求完成账号验证。
  2. 打开模型广场，确认准备使用的模型、价格、权限和速度限制。
  3. 进入API 密钥页面点击“新建 API 密钥”，复制并妥善保存。
  4. 在澄答 AI“API 设置”选择“硅基流动”，填写 Key，并从推荐项选择或手动粘贴完整模型 ID，保存后测试连接。

Base URL

https://api.siliconflow.cn/v1

密钥安全

API Key 只填写在澄答 AI 中，不要上传到公开仓库。发现泄露时立即删除并重新创建。

2. 模型自选与语音配置

文本、截图和语音模型均可从软件推荐项选择，也可手动填写模型广场显示的完整模型 ID。

用途软件预设说明
文本回答Qwen/Qwen3-14B用于普通文本和语音转写后的直接回答，可替换为账号有权限的兼容对话模型。
截图识题Qwen/Qwen3-VL-8B-Instruct需要选择支持图片输入的视觉语言模型。
语音识别FunAudioLLM/SenseVoiceSmall通过 Audio Transcriptions 流程上传语音片段并返回转写文本。
关于语音热词当前澄答 AI 的手动热词表用于百炼实时语音线路；选择硅基流动时不会显示该设置。硅基流动语音模型的具体能力以模型广场和官方接口文档为准。

3. 费用、余额与限流

免费模型、赠送金额、单价和限流可能随模型及活动变化，使用前以硅基流动控制台的实时信息为准。

余额与计费

免费模型以模型广场的“免费”标记为准；付费模型按官方当期输入 / 输出 Token、语音时长或对应能力单位计费。

调用与限流

模型权限、余额、并发及速率限制由硅基流动控制台管理。遇到 429 或额度错误时，先检查余额、模型权限和当前限流。

新用户赠送金额注册活动和赠送金额可能随时间与渠道变化，请以账号“余额 / 账单”和当期活动页实际显示为准。
