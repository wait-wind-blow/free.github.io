AI SERVICE SETUP

选择 AI 服务商

首次配置时，阿里百炼和硅基流动任选一个即可，不需要同时开通。选择后按照对应页面创建 API Key，并在澄答 AI 中选择同一个服务商。

推荐

阿里百炼

适合新用户。澄答 AI 的默认快速模型、截图模型、实时语音和语音热词均已按百炼线路配置。

  • 默认快速模型开箱可选
  • 支持实时语音与手动热词表
  • 说明新用户额度、按量付费和 Token Plan
打开阿里百炼配置

硅基流动

原有线路继续保留。已经在使用硅基流动的用户无需更换，可继续使用原来的 API Key 和自选模型。

  • 保留原有兼容配置
  • 文本、截图和语音模型可自选
  • 单独说明账号、密钥、计费与限流
打开硅基流动配置
只配置一个就能使用API Key、Base URL 和模型必须来自同一个服务商。以后需要切换时，再在软件“API 设置”中选择另一服务商并保存对应配置。
